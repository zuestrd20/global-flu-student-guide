# 世界流感三十年｜學生探索室

繁體中文學生科學教育網站。歷史主窗為 1996–2025；2026 獨立標示，不假造完整年度數字。

## 使用

純靜態 HTML/CSS/JavaScript，無套件、追蹤器、登入或第三方字型。GitHub Pages 從 main 根目錄發布。

本地檢查：`node --check app.js`，`node --check data.js`。以一般 HTTP 靜態伺服器開啟 index.html。

## 資料原則

每個數字標示地區、期間、年齡／分母、指標、估計區間和來源。模型有症狀發病、通報確診與陽性檢體不互相冒充；不同國家口徑不做高低排名。CDC 同系列季別圖保留 2020/21 缺值。

僅一般教育，不提供個人診斷或處方。文字為原創摘要，來源仍保有其原始權利。資料與方法請見網站來源段落。
